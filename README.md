# 우리집 청약 전략실

가구 프로필을 한 번 저장하고, 입주자모집공고 PDF만 바꿔 넣으면
**청약 자격 → 평형·유형별 실제 물량 → 당첨확률 추정 → 계약금·중도금·잔금 자금 플랜**까지
한 번에 계산하는 순수 정적(서버리스) 웹앱입니다.

## 주요 기능

- **공고문 PDF 자동 분석**: 공급표·분양가·납부일정·발코니/유상옵션·중도금 대출조건·주택관리번호 추출 (브라우저 안에서만 처리, 업로드 없음)
- **자격·배점 자동 판정**: 일반공급 가점(84점), 다자녀 배점(100점), 신혼·생초·신생아 소득단계(2025 도시근로자 소득표)
- **청약홈 실데이터 연동**: 공공데이터포털 인증키만 넣으면 단지별 일반 경쟁률·해당지역 최저가점(커트라인)·특공 유형별 신청현황을 불러와 당첨확률 추정에 반영
- **자금 플랜**: 회차별 현금흐름, 중도금 이자(후불/월납), 스트레스 DSR·LTV·수도권 총액상한 기반 잔금대출 한도, 취득세

## GitHub Pages 배포

1. 이 폴더(v3)를 GitHub 저장소로 push
2. 저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 선택
3. 1~2분 후 `https://<계정명>.github.io/<저장소명>/` 접속 — 모바일 브라우저에서 "홈 화면에 추가"하면 앱처럼 사용 가능

> PDF 분석은 CDN(pdf.js)을 사용하므로 인터넷 연결이 필요합니다.
> 입력한 가족·자금 정보와 인증키는 전부 사용자의 브라우저(localStorage)에만 저장됩니다.

## 청약홈 API 키 (선택)

[공공데이터포털](https://www.data.go.kr)에서 아래 두 서비스를 무료 활용신청 후, 발급된 일반 인증키를 전략 탭의 「청약홈 실제 경쟁률 불러오기」에 입력하세요.

- 청약홈 청약접수 경쟁률 및 특별공급 신청현황 조회 서비스 (15098905)
- 청약홈 분양정보 조회 서비스 (15098547) — 단지명 검색용(선택)

## 개발

```bash
npm test        # rules.js 단위 테스트
npm run build   # dist/server/index.js (워커 번들, 선택)
```

정적 파일(index.html, styles.css, rules.js, app.js)만으로 동작하며 빌드 과정이 필요 없습니다.

## 면책

본 계산기는 참고용입니다. 청약 자격·배점·소득기준은 공고문 원문과 청약Home 판정이 우선하며,
대출 한도·세금은 금융기관 심사와 실제 잔금일 기준으로 달라질 수 있습니다.
